        Mode d'emploi

        Impression avec Zebra Designer Essentials 3 et colisage par scan.

        1. 1
          Étiquette simple (.NLBL)

          Complétez le formulaire (article, couleur, manche, taille, OF, type) puis « Générer le fichier .NLBL » (ou Ctrl + ⏎). Si l'article existe en plusieurs tailles, la fenêtre demande la quantité de CHAQUE taille (0 pour en ignorer une) : toutes les tailles sont générées en même temps.

        2. 2
          Lot d'étiquettes (.zip)

          Ajoutez chaque référence à la file d'impression (jusqu'à 100, Ctrl + M), puis « Générer le lot » : vérifiez les copies ligne par ligne, vous obtenez une archive .zip avec un .nlbl par étiquette et un LISEZMOI.txt.

        3. 3
          Impression

          Ouvrez le .nlbl dans Zebra Designer 3 : les 7 variables sont déjà remplies. Réglez « Nombre d'étiquettes » puis imprimez.

        4. 4
          Imprimante cible

          Le fichier vise « ZDesigner GK420d » par défaut. Pour une autre imprimante, ouvrez les préférences (icône réglages) : le nom est intégré au .NLBL sans toucher au design.

        5. 5
          Ancien flux (.TXT)

          « Exporter le fichier .TXT » conserve le format Clé=valeur à charger via « Charger… » dans Zebra Designer.

        6. 6
          Colisage

          Onglet « Colisage » : collez les codes scannés (ou importez un .txt/.csv), puis « Générer le colisage ». Regroupement OF → modèle → couleur → taille, quantités comptées, codes inconnus signalés, copie pour Excel et export CSV. « code×N » compte N pièces.

        Bon à savoir
        • Tout est calculé dans le navigateur : la page fonctionne hors ligne, sans serveur.
        • Le journal, les derniers OF et les préférences sont enregistrés dans ce navigateur uniquement.
        • Les codes SPE générés sur ce poste sont mémorisés pour être reconnus au colisage ; sinon, saisissez l'OF du lot.
        • Une étiquette strictement identique ajoutée à la file augmente la quantité de la ligne existante.
